# VolaFin

Personal finance management platform for tracking money.

## Features

- **Multi-Account Management**: Bank accounts, cash, mobile money
- **Income & Expenses Tracking**: Categorized transactions
- **Recurring Expenses**: Automated tracking
- **Real-time Balance**: Available balance across all accounts (SDR)
- **Admin Dashboard**: Full control over finances

## Tech Stack

- Next.js 16
- TypeScript
- TailwindCSS + shadcn/ui
- Zustand
- TanStack Query
- Axios
- Recharts (charts)
- next-intl (i18n)
