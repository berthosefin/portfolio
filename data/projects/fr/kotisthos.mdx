# Kotisthos

Complete ERP system designed for associations with multiple management modules.

## Features

- **Members Management**: Complete CRUD for member data
- **Subscriptions**: Track membership fees and payments
- **Accounting**: Double-entry bookkeeping
- **Dashboard**: Real-time statistics and insights

## Tech Stack

- Next.js 16
- TypeScript
- Zustand (state management)
- TanStack Query (data fetching)
- Axios
- shadcn/ui
- Zod (validation)
